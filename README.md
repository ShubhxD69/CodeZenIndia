# CodeZenIndia

A modern Python IDE built with PyQt6 featuring:
- Auto updates
- Integrated terminal
- Python interpreter management
- Persistent settings
- GitHub release updater
- Professional developer tools

## Features

- Modern dark UI
- Multi-tab code editor
- Built-in terminal
- Python interpreter manager
- Auto-save support
- Workspace restore
- GitHub auto-update system
- Custom installer
- PyInstaller production build
- Status bar interpreter switcher
